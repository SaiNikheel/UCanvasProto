# UCanvasProto

Universal Canvas Protocol (CUP) — Pioneering the Next Generation of Agent-Computer Interaction (ACI)

UCanvasProto is an open-source project to design, specify, and implement the Universal Canvas Protocol (CUP): a cross-platform, declarative middleware and rendering layer that allows AI agents to stream interactive, brand-compliant UI components into host applications and receive bi-directional state updates.

Repository: https://github.com/SaiNikheel/UCanvasProto

License: MIT

---

## Vision

Move Human-Computer Interaction (HCI) forward into Agent-Computer Interaction (ACI) by replacing linear, text-first chat interfaces with persistent, interactive canvases that preserve brand identity, reduce user friction, and enable collaborative agent workflows.

## Goal

Ship an open, secure, and extensible protocol (CUP) and reference implementations that let LLM-powered agents stream native, interactive UI components to hosts (web, iOS, Android, cross-platform) while allowing hosts to inject brand themes and maintain secure, low-latency bidirectional state synchronization.

## Objectives (initial commit)

1. Publish a v0.1 CUP specification draft and reference web renderer.
2. Commit a clear, export-ready business proposal (PROPOSAL.md) describing the problem, market, architecture, and go-to-market plan.
3. Provide sample demos and example payloads for common flows (flights, product configurator, CRM dashboard).
4. Create a cross-platform roadmap and seed SDKs for Web and mobile.
5. Establish open governance, contribution guidelines, and a component audit process.

## Open Source Ideology

We believe open source accelerates adoption, improves security through transparency, and fosters a community of interoperable components. UCanvasProto will:

- Publish the core protocol and reference renderers under an open-source license (MIT).
- Encourage community contributions to the spec, SDKs, and component marketplace.
- Run an open RFC process for breaking changes to the protocol.
